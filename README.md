# M2-SMA

Submission of the IMAGINE Master 2 SMA project.

The project consists of an Axelrod tournament (prisoner's dilemma)
using a dynamic strategy with an LLM.

## Authors
#### Clément Potier
#### Mickaël Longlade
#### Rémy Guibert

## Python Version
#### Python 3.13

## Run the code
Install the dependencies with `pip install -r requirements.txt`.

Create a file named `config.py` that contains a variable string named "API_key".

This API key is a pasword to run your Google LLM, you can obtain one free by going on this [website](https://aistudio.google.com/api-keys).

Then run the program `main.py`.
